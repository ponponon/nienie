FAQ

常见问题解答。

关于连接方式、隐私安全与多设备支持的直接说明。

Nienie 会上传我的 API Key 或源代码吗？+

不会。所有模型调用、文件读写和命令执行均在你自己的电脑本地完成。手机端只通过 WebSocket 接收脱敏后的统一事件流，绝不读取或传输你的 API Key。

手机和电脑不在同一个 Wi-Fi 下可以使用吗？+

可以。Nienie 支持局域网直连、USB 端口映射以及跨网加密 Relay（默认提供公网 Relay 节点，你也可以在桌面端一键切换为自己私有部署的 Relay 地址）。

电脑端重启后手机需要重新扫码配对吗？+

不需要。配对成功后，电脑端与手机端均会持久化保存加密设备令牌，电脑重启 Bridge 或手机重开 App 都会在后台自动免扫码重连。

一台手机可以同时连接并管理多台电脑吗？+

可以。在手机端抽屉左上角点击当前电脑名称，即可随时在多台已绑定的电脑（如办公室 MacBook、家里台式机或 Linux 开发机）之间秒级切换。
