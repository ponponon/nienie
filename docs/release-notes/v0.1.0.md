## Features

- **First installable macOS build.** The DMG is signed with a Developer ID Application certificate, notarized by Apple and stapled, so Gatekeeper reports `Notarized Developer ID` and the app opens on a plain double-click — no right-click → Open workaround.
- **Android client ships at 14.7 MB.** arm64-v8a only, legacy jniLibs packaging, R8 obfuscation and stripped debug symbols: 78% smaller than the default build, which is what makes a slow mobile download tolerable.
- **Both platforms from a single tag.** Versioning, code signing, notarization and uploading all run inside GitHub Actions. No signing key ever leaves CI.

## Known Limitations

- Intel (x64) DMG is not available yet: the `@matrixai/quic` native dependency only ships arm64 binaries.
- The Android build targets `arm64-v8a` only, so 32-bit devices from before 2017 cannot install it.
