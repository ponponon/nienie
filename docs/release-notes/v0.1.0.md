首个可安装版本：macOS 安装包（Apple 芯片）+ Android APK。

## 亮点

- **桌面端出 DMG 了。** 已用 Developer ID Application 签名、Apple 公证并钉入票根，Gatekeeper 判定 `Notarized Developer ID`，双击直接启动，不需要「右键 → 打开」绕过。
- **移动端体积砍到 14.7 MB。** 只保留 `arm64-v8a`、开启 zip 对齐与符号剥离、R8 混淆，从默认构建的 66.5 MB 降了 78%，弱网下载体验差别很大。
- **两端首次同版本发布。** 版本号统一由 `v*` tag 驱动，签名、公证、打包、上传全部在 GitHub Actions 里跑完，本地不留私钥。

## 已知限制

- Intel（x64）DMG 暂未提供：原生依赖 `@matrixai/quic` 目前只有 arm64 二进制。
- Android 端仅提供 `arm64-v8a`，2017 年以前的老设备（32 位）装不上。
