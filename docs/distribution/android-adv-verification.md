# Android 侧载 ADV 开发者身份验证(国内四厂)

## 背景

2026-11-09 起,OPPO、vivo、小米、荣耀(移动智能终端生态联盟)在中国大陆对**侧载安装**的 APK
启用开发者身份验证(ADV,Android Developer Verification)。未验证应用安装时会弹
「开发者身份未验证」提示(如 OPPO 的"个人信息收集提醒 / 信息收集风险"同属这一套合规弹窗),
用户手动确认后**仍可继续安装**,不是硬拦截。

- 验证对象:开发者实名身份 ↔ **包名 + 签名** 的归属关联。不是病毒检测,不审计代码。
- 四家**验证结果互认**:任选一家做一次即可。
- 与 Google 海外 ADV 是两套体系;Google 那套不含中国大陆无 GMS 设备,**不需要向谷歌申请**。
- 商店在架应用由平台自动验证;**纯官网/侧载分发的应用(我们)必须手动补验证**。

## 流程(OPPO 开放平台 / 小米澎湃OS开发者平台,任选其一)

1. 注册开发者账号 + 个人/企业实名认证(约 1-3 个工作日)。
2. 「应用管理 → 应用验证」:下载平台的**含签名 APK 空包**,用 Nienie 发布签名密钥签名后回传。
3. 关联包名 `cn.quniv.nienie_mobile`(可批量,一签名可绑多包名)。
4. 机审即时生效,结果同步到四家的侧载安装环节。

## 维护注意

- **换包名或换签名必须重新提交验证**(签名是互认的锚)。官网 APK 与 CI 发布必须用同一签名密钥。
- 商店在架包更新会自动同步,侧载包不会。
- 未验证只影响安装摩擦(多一次确认),不影响功能;用户当前点「继续安装」即可。
- 另:安装时的「检测结果:涉及敏感权限」指 `CAMERA`(扫码配对),属正常提示。
