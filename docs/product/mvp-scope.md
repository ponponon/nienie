# Nienie MVP 范围

## 用户故事

用户在电脑上运行 OpenCode 或 Codex，离开电脑后，可以通过手机：

1. 查看电脑是否在线。
2. 查看本机可用的 Agent。
3. 查看当前会话。
4. 进入会话并查看实时输出。
5. 发送下一条消息。
6. 看到工具调用、执行结果和错误。
7. 在连接中断后重新接管会话。

## MVP 不做

- 不做账号系统。
- 不做云端中继。
- 不做跨用户共享。
- 不做完整远程桌面。
- 不做通用终端模拟器。
- 不做 Claude Code、Pi、OpenClaw 适配。
- Claude Code、Pi、OpenClaw 属于后续版本，不代表产品长期不支持这些 Agent。
- 不做复杂 Agent 编排。
- 不做支付和订阅。

## 验收标准

- OpenCode 和 Codex 至少能被 Bridge 正确探测。
- 手机能通过一次性配对连接 Bridge。
- 手机能看到 Agent 和会话列表。
- 用户消息能从手机发送到正确的会话。
- 文本流能实时到达手机并按顺序展示。
- 工具调用和结果能正确配对。
- Bridge 重启或手机断线后，已完成事件不会重复展示。
- 未配对设备无法发送消息、取消会话或执行审批。
